## 需要确定的数据设置

商品已在售，但库存为0，不能购买。账号名称虽为admin，但角色仍是普通用户，不能进入后台。已请求用户选择是否提升该账号权限，以及使用演示库存还是保留真实库存待后台填写。确认前不执行这两项数据库更新。

## 代码联动与兼容

后台保存通过现有 Service 和 Repository 写入 products。前台列表与搜索直接查询全部在售商品，首页从在售商品中随机取最多4件，购买时按数据库库存校验并在下单事务中扣减。无须为每件商品修改首页代码。

实际 products.name 为 VARCHAR(100)。后台字段和服务端校验已对齐100字符，避免输入超过实际列长度后产生数据库错误；没有执行 ALTER TABLE。

新增完整链路测试：后台上架 → 数据库保存 → 商品搜索与详情 → 推荐候选 → 购物车 → 下单扣库存 → 模拟支付。测试仅使用 H2，不在真实 MySQL 试购。

## 浏览器后续操作

管理员角色设置后，应退出重新登录，以刷新当前会话权限。进入 `/admin/products` 设置库存并上架；通过 `/products` 搜索；首页 `/home` 随机推荐；用户进入详情后加入购物车并结算。数据库密码与商城登录密码是不同用途，本轮未更改商城密码。
